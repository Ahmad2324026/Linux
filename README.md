# Linux System Monitor

## Project Description

This project is a Linux monitoring tool developed using Python.

It monitors:
- CPU Usage
- RAM Usage
- Disk Usage
- Running Processes

The project demonstrates operating system concepts such as:
- Process Management
- Memory Management
- System Monitoring

## Technologies Used

- Python
- psutil
- rich
